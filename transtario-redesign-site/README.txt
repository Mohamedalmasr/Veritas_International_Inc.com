Transtario static website redesign

Files:
- index.html: single-page responsive HTML site with embedded CSS and JavaScript.

Notes:
- The quote forms are static and open an addressed email draft to transtario@hotmail.com.
- Fleet imagery is loaded from the current Transtario website. To make the site fully offline, download those images and update the image src URLs in index.html.
- To publish, upload index.html to any static host or replace the existing website homepage.
